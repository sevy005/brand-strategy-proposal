# 逐页提案蓝图

按用户需要的页数与模块选用；28页为完整提案参考，不是固定要求。目录：P01—P03任务，P04—P09研究与机会，P10—P12品类定位与价值，P13—P18产品、语言与信任，P19—P25总图、视觉和触点，P26—P28落地与决策。


替换文中的【变量】即可写成正文。事实尽量引用F编号，分析结果沿用D编号。建议图表用于说明内容，不要求每页都画复杂模型。

### P01｜封面与项目命题

**公式：品牌 + 明确任务 + 优先价值/机会方向。**

标题模板：

> 【品牌】品牌策略提案：围绕【主导价值】，建立【品类/主推产品】的新认知。

正文模板：

> 本次项目聚焦【商业问题】。我们将从【人群与场景】出发，明确【品类选择】，以【产品】承接【主导价值】，形成从产品、表达、识别到渠道的执行方案。

图表：品牌与产品主图。检查：标题是否说明本案做什么，而不只是“品牌升级方案”。

### P02｜商业问题

**公式：目标与现状差距 + 具体环节 + 证据 → 首要问题。**

标题模板：

> 【品牌】当前优先需要解决的是【具体问题】。

正文模板：

> 根据【F02/F11等依据】，品牌目前出现【事实表现】。这一问题主要发生在【认知/选择/购买/体验等环节】，影响【业务目标】。因此，本次首先解决【D01】，其他事项按影响和资源排序推进。

图表：现象—环节—影响—优先任务。检查：有事实连接，避免把所有问题都归为知名度不足。

### P03｜业务目标与边界

**公式：要改变什么 + 如何衡量 + 何时判断 + 能调整什么。**

标题模板：

> 本次目标是让【对象】从【当前状态】进入【目标状态】。

正文模板：

> 在【周期】内，本案优先推动【目标行为或业务改善】，以【基线、目标和口径】判断进展。可调整事项为【范围】，已明确的约束为【限制】。尚未确定的数值保留为【待补充】，不替代为估计目标。

图表：目标、指标、范围、约束四栏。检查：有基线和口径；没有时写清补充责任。

### P04｜市场变化与机会背景

**公式：观察到的变化 + 证据范围 + 对品牌选择的影响。**

标题模板：

> 【已观察到的变化】，正在影响【具体选择或需求】。

正文模板：

> 【F07】显示，在【时间、地区或渠道范围】内，【具体变化】正在发生。对【目标人群】而言，这意味着【需求/决策变化】。本案据此考虑【机会方向】，并将【尚未确认的外推】保留为待验证假设。

图表：变化—用户影响—项目影响。检查：没有资料时写“市场变化待补充”，改用已知场景问题展开。

### P05｜竞争与替代方案

**公式：用户现有选择 + 同维度比较 → 已有价值与具体不足。**

标题模板：

> 现有方案主要强调【共性】，本案需要进一步验证【具体不足】。

正文模板：

> 在已收集的【F05/F06】中，【竞品或替代方案】分别以【主张】服务【对象】，价格与证据为【资料】。我们观察到【具体差异/不足】，因此提出【候选方向】。该判断适用于当前样本，不等同于整个市场无人提供。

图表：方案、对象、主张、产品、价格、证据、渠道。检查：同价值竞争必须说明具体差别。

### P06｜原点人群

**公式：需求强度 + 场景相关性 + 产品匹配 + 可触达性 → 优先人群。**

标题模板：

> 先服务【原点人群】，优先进入【场景】。

正文模板：

> 根据【F03/F04】，我们优先服务【具体人群】，因为他们在【场景】中有【需求】，现有【资源与渠道】也较能承接。购买者是【角色】，使用者是【角色】，影响决策的是【角色】；三者的需求分别为【要点】。

图表：购买者—使用者—影响者。检查：人群由需求与行为界定，不能只有年龄和城市。

### P07｜消费洞察

**公式：场景 + 想完成的任务 + 阻碍 + 当前办法不足 + 选择触发点。**

标题模板：

> 在【场景】中，用户需要【任务】，却被【阻碍】影响。

正文模板：

> 当【触发时刻】出现时，【人群】希望【完成任务】，目前通常采用【现有办法】。根据【原话/行为及F编号】，主要不便是【具体问题】。我们判断【改善因素】可能改变其选择，需通过【方法】确认其重要性。

图表：触发—行为—阻碍—判断—购买。检查：购买动机与心理解释有依据，假设不伪装成用户原话。

### P08｜核心资源与兑现边界

**公式：已有资源 → 可支持的利益；缺口 → 建设任务。**

标题模板：

> 【核心资源】为【主导价值候选】提供兑现基础。

正文模板：

> 【品牌】现有的【产品、技术、供应或服务能力】，根据【F01/F08】能够支持【具体利益】。其中【事项】已具备，【事项】需投入后建设，【事项】短期无法确认。策略承诺以已有能力及明确建设计划为边界。

图表：已具备、待建设、不可承诺。检查：荣誉、规模和工厂照片不能自动证明具体产品利益。

### P09｜机会筛选

**公式：需求重要 + 方案不足 + 资源匹配 + 经营可行 → 推荐机会。**

标题模板：

> 优先验证【机会A】，因为它同时连接【需求】与【能力】。

正文模板：

> 对比【有依据的候选方向】，我们以需求重要性、竞争差别、企业兑现能力及经营条件进行判断。推荐【方向A】，依据是【事实】；暂缓【方向B】，因为【具体限制】。决定是否继续的关键假设是【假设】，验证方式为【方法】。

图表：候选方向×四项条件，标注“支持/不足/未知”及依据。检查：资料只有一个方向时，不硬造陪衬方案。

### P10｜品类选择与取舍

**公式：已知品类认知 + 优先人群/场景 + 价值切口 + 经营边界。**

标题模板：

> 以【品类身份】进入【场景】，先做清【核心利益】。

正文模板：

> 本案选择【强化既有品类/进入细分品类/围绕场景组织产品等路径】。用户可以先通过【熟悉品类】理解产品，再认识【差异利益】。优先投入【事项】，暂不优先【事项】，理由分别为【依据】。

图表：母品类—价值切口—品牌位置。检查：新名称只是表达建议，不自动构成新品类。

### P11｜品牌定位

**公式：人群 + 场景 + 品类身份 + 主导价值 + 兑现依据。**

标题模板：

> 【品牌】，为【原点人群】提供【主导价值】的【品类身份】。

正文模板：

> 面向【D03】，在【D04】中，【品牌】以【D06】提供【D09】，定位为【D07中的品牌身份】。这一选择回应【需求】，相对当前方案的具体区别是【差异】，并由【证据或待验证条件】支撑。

图表：一条定位句及其四项依据。检查：换成多个竞品名称仍适用时，继续具体化差异。

### P12｜主导价值

**公式：产品特征 → 功能利益 → 体验利益 → 一项主导价值。**

标题模板：

> 让用户优先记住【主导价值】。

正文模板：

> 【产品特征】帮助用户【完成任务】，带来【体验利益】。因此，我们以【D09】作为首要表达。【支持利益1】用于证明价值，【支持利益2】用于消除【购买障碍】。所有主信息围绕这一优先级组织。

图表：主导价值居中，利益与证据围绕。检查：一项主导价值不是把多个形容词拼成一个长词。

### P13｜产品矩阵

**公式：不同需求任务 + 产品角色 + 规格与价格关系。**

标题模板：

> 以【主推产品】建立认知，用【其他产品】承接不同任务。

正文模板：

> 【产品A】优先承担【主销/形象/首购等角色】；【产品B】承接【不同场景或需求】。系列之间按【规格、对象、功能或场景】区分，价格关系由【依据】决定。资源首先集中在【主推产品】，其余产品共享【长期资产】。

图表：对象/场景—产品—角色—价格—识别。检查：单产品项目可简化，不为凑矩阵增加虚构产品。

### P14｜战略大单品

**公式：人群场景 + 第一价值 + 产品定义 + 证据 + 经营与体验。**

标题模板：

> 优先推出/强化【产品】，集中兑现【第一价值】。

正文模板：

> 我们推荐【D11】作为主推单品，解决【D03】在【D04】中的【D05】。其第一价值为【D09】，产品必须具备【规格/结构/服务】。通过【D14】支持承诺，并由【价格、供应、渠道和体验条件】承接；未确认项为【事项】。

图表：大单品定义卡。检查：一张漂亮产品图不能替代产品定义。

### P15｜价格与经营承接

**公式：用户比较对象 + 可感知价值 + 成本供应约束 → 价格与渠道建议。**

标题模板：

> 【价格建议/待验证区间】需要由【具体价值与条件】支撑。

正文模板：

> 用户将本品与【参照方案】比较，可感知差别为【利益与证据】。结合【F01/F09】中的售价、成本口径、渠道费用和供应限制，建议【安排】。价格接受度、利润或供应尚未确认时，先完成【验证任务】，不写成已成立的经营结论。

图表：参照产品—价值差—价格—约束—待验证条件。检查：不凭“高端感”直接得出溢价比例。

### P16｜名称体系

**公式：熟悉品类 + 利益/形态/场景/认知线索，选择一条最清楚的路径。**

可选句式：

- 【利益词】+【品类词】。
- 【形态/材料词】+【品类词】。
- 【场景/人群词】+【品类词】。
- 【熟悉的认知意象】+【品类词】。

正文模板：

> 建议以【候选名称】表达【核心利益】。它借助【熟悉认知】帮助用户理解【产品事实】，并与品牌名【品牌】保持清晰层级。【其他名称】分别用于【系列/技术】，不同时争夺第一记忆。候选可用性待确认。

图表：品牌名—产品名—系列名—技术名。检查：不以名字新奇替代产品与价值差异。

### P17｜主传播语言

**公式：选择一个传播任务，再选合适句式。**

可选句式：

- 价值直述：【品牌/产品】，让【具体任务】更【可感知利益】。
- 场景触发：【出现具体场景】时，用【品牌/产品】完成【任务】。
- 问题解答：【真实困扰】？【品牌/产品】提供【有依据的答案】。
- 行动指令：【做一个具体动作】，获得【对应利益】。
- 产品记忆：【产品名】，【一句自然、可复述的价值表达】。

正文模板：

> 本案主传播语言为【D13】，优先完成【解释价值/触发场景/行动等一项任务】。第一层讲【核心利益】，第二层补充【证据】，第三层解释【选择或使用信息】。不同触点调整长度，主张保持一致。

图表：主口号—卖点—证据—场景话术—行动。检查：不强迫所有文案押韵，不把未经证实的绝对承诺写进口号。

### P18｜信任体系

**公式：承诺 → 用户疑问 → 所需证据 → 当前状态 → 补齐行动。**

标题模板：

> 用【真实证据】支持【核心承诺】。

正文模板：

> 用户对【承诺】最可能追问【问题】。目前【证据】可支持【明确范围】；【资料】尚待核实；【测试/服务/透明说明】需要建设。对外表达仅使用与证据条件相符的说法，缺口由【负责人】通过【行动】补齐。

图表：逐项主张—证据台账。检查：企业证据、产品证据和体验反馈分开使用。

### P19｜一页策略总图

**公式：把D01—D18压缩成一个可追溯的选择链。**

正文模板：

> 为解决【D01】，我们抓住【D02】，先服务【D03】的【D04】。以【D07/D08】建立品牌角色，聚焦【D09】，用【D11】兑现。通过【D12/D13】建立记忆，以【D14】支持信任，由【D15/D16】进入购买场景，按【D17/D18】执行与验证。

图表：纵向策略链或一页总图。检查：任何一项都能对应前面的事实与选择。

### P20｜视觉转译

**公式：价值 → 感受 → 具体图像方法 → 识别规则。**

标题模板：

> 把【核心利益】变成看得懂、认得出的【视觉线索】。

正文模板：

> 【D09】需要被感知为【具体感受】。因此，以【主体】配合【动作/结构】表现【利益】，用【材质/空间/色彩】强化感受。固定识别资产为【符号、字形等】，可变化部分为【场景、系列色等】；每项选择对应【价值或产品依据】。

图表：价值—感受—字/色/图/物对应表。检查：颜色或IP不能仅由设计偏好决定。

### P21｜核心业务载体

**公式：首要购买任务 + 信息顺序 + 真实尺度 → 核心载体设计。**

标题模板：

> 让【包装/产品机身/菜单/门店等载体】先讲清【第一价值】。

正文模板：

> 在【购买场景】中，用户首先需要识别【品牌/品类】，随后判断【利益、证据和规格】。因此，载体按【信息顺序】组织，固定【核心识别】，以【差异元素】区分系列；通过【真实大小/陈列方式】验证可读与可选。

图表：主面/首接触面、系列与实景。检查：选择与实际业务有关的载体，不堆无关周边。

### P22｜手机首屏或销售首触点

**公式：我是谁 + 对你有什么价值 + 必要证据 + 下一步。**

标题模板：

> 第一眼讲清【品类身份】与【主导价值】。

正文模板：

> 首屏面向【对象】，优先展示【产品名/品类】与【价值句】，通过【产品主体与证据】帮助判断，再引导【查看规格/选择产品/咨询等行动】。较复杂的机制说明放入后续内容，不与第一信息争抢。

图表：手机首屏或现场首接触示意。检查：缩到实际阅读大小后，核心信息仍然可读。

### P23｜详情与购买决策

**公式：适不适合我 → 利益是什么 → 凭什么 → 如何选 → 如何用 → 下一步。**

正文模板：

> 第一部分用【场景与问题】帮助用户判断适合性；第二部分说明【利益】；第三部分以【结构/机制/证据】解释依据；第四部分列出【规格、价格和差异】；第五部分说明【使用与服务】；最后提供【行动入口】。

图表：逐屏内容结构。检查：参数、限制与选择信息有明确位置，长图氛围不能替代逐屏阅读。

### P24｜沟通矩阵

**公式：对象×场景×触点×首要信息×证据×行动×指标。**

正文模板：

> 购买前，在【触点】向【对象】讲【场景/价值】，引导【行动】；购买中，通过【触点】补充【证据与选择信息】；使用后，以【服务与内容】兑现【体验】。各渠道共享【名称、主张与识别】，按任务调整内容。

图表：以上七列矩阵。检查：每个重点触点都有职责，不把同一海报简单复制到所有渠道。

### P25｜完整用户体验

**公式：购买前被理解 + 购买中好选择 + 使用中有兑现 + 使用后有承接。**

标题模板：

> 让【主导价值】贯穿用户与产品的每次接触。

正文模板：

> 用户在【首次接触】应理解【价值】；选择时应获得【规格与证据】；开包/使用时应感受到【与承诺相符的体验】；出现问题时通过【服务】得到处理。后续以【维护、补充购买或其他适合业务的方式】持续承接。

图表：阶段—承诺—动作—负责人。检查：品牌承诺不能只停留在广告与包装。

### P26｜落地安排

**公式：先补基础 → 小范围验证 → 达到条件后扩大。**

正文模板：

> 第一阶段由【负责人】完成【产品、证据、语言及核心资产】，投入【资源】；第二阶段在【人群/渠道范围】验证【关键假设】；满足【条件】后，再扩大【产品/渠道】。预算优先支持【决定性任务】，未确认项为【事项】。

图表：阶段、行动、负责人、时间、资源、进入下一阶段条件。检查：阶段时间按项目填写，不把固定天数套成事实。

### P27｜效果验证

**公式：要验证什么 + 基线 + 目标/判断条件 + 口径 + 数据 + 调整。**

正文模板：

> 我们先验证【理解/选择/经营/体验假设】，以【基线】为参照，在【周期】内观察【指标】。数据来自【来源】，由【负责人】按【口径】记录。出现【情况】时调整【事项】，避免把产品、价格、投放等共同影响全部归因于视觉变化。

图表：假设—指标—口径—周期—责任—调整条件。检查：目标值没有依据时保留待定，不虚构增长比例。

### P28｜推荐与本次决策

**公式：一个推荐方向 + 依据 + 取舍 + 下一步 + 未决事项。**

正文模板：

> 本案推荐【方向】，以【品类身份】服务【人群】的【场景需求】，通过【产品】兑现【主导价值】。推荐依据是【事实与判断】，暂缓【事项】是由于【限制】。本次需要确定【决策】，决定后先执行【行动】；尚待确认【关键事项】。

图表：推荐、决定、行动、未决四栏。检查：清楚表达客户要决定什么，不以感谢页代替决策收束。
