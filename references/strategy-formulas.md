# 策略公式、D变量与判断分支


**方案 = 用事实定义问题 + 选定有条件成立的机会 + 聚焦一个用户价值 + 用产品和证据兑现 + 用语言与视觉建立记忆 + 用触点和行动落地。**

本文中的“+”“∩”“→”表示信息组合、条件交集或推导关系，不是数学预测模型。

### 公式A：机会

**机会 = 重要需求 ∩ 现有方案不足 ∩ 企业可兑现能力 ∩ 经营可行性。**

直接套用：

> 对【核心人群】而言，【场景需求】很重要，但现有【产品/替代方案】在【具体环节】仍有不足。根据【证据编号】，我们判断【企业资源】能够支持一个以【核心利益】为主的机会方向；【未确认条件】需要先验证。

### 公式B：定位

**定位 = 为谁 + 在何时 + 属于何类 + 提供什么优先价值 + 凭什么做到。**

直接套用：

> 【品牌】面向【原点人群】，在【关键场景】中，以【核心资源/产品能力】提供【主导价值】，定位为【明确的品类身份】。

### 公式C：价值

**产品特征 → 使用利益 → 可感知体验 → 容易复述的表达。**

直接套用：

> 【产品特征】的价值在于帮助用户【完成具体任务】。用户能够直接感受到【体验】，因此我们的首要表达是【主导价值】，其依据为【证据】。

### 公式D：大单品

**大单品 = 明确人群与场景 + 第一价值 + 产品定义 + 名称 + 证据 + 经营承接 + 体验。**

直接套用：

> 以【产品】作为优先推进的主推单品，服务【人群】的【场景需求】。围绕【第一价值】，产品必须具备【规格/结构/服务】，通过【证据】支持承诺，并由【价格、供应和渠道安排】承接。

### 公式E：传播

**传播信息 = 本触点任务 + 价值/场景/行动中的一个重点 + 品牌或产品记忆 + 必要证据。**

直接套用：

> 在【触点】面对【对象】，先让用户明白【一个重点】，用【产品名/识别资产】形成记忆，以【证据】帮助判断，引导【下一步行动】。

### 公式F：视觉

**主导价值 → 应有感受 → 主体/动作/空间/材质/颜色/信息 → 真实业务载体验证。**

直接套用：

> 为了让用户感受到【主导价值】，画面以【产品/人物】为主角，通过【具体动作与结构】呈现【利益】，再用【材质、颜色、空间】强化感受；在【包装/首屏/现场】检查是否仍能读懂。

### 公式G：落地

**行动 = 做什么 + 谁负责 + 何时完成 + 投入什么 + 如何判断 + 何时调整。**

直接套用：

> 由【负责人】在【时间】前完成【行动】，投入【资源】，通过【指标与口径】验证【假设】；出现【判断条件】时，调整【产品/表达/渠道】。

## 3. 先统一18个策略变量

这些是由事实推导的结果，不是要求客户提前填写的答案。每项记录“结果、依据、推导、状态”。

| 编号 | 变量 | 从哪里来 | 主要用途 |
| --- | --- | --- | --- |
| D01 | 商业问题 | 目标、现状与具体业务环节 | 决定整案任务 |
| D02 | 机会判断 | 需求、竞争、资源与经营条件 | 决定是否值得进入 |
| D03 | 原点人群 | 购买、使用、需求与触达证据 | 决定优先服务谁 |
| D04 | 关键场景 | 用户行为、触发时刻与使用记录 | 决定需求如何发生 |
| D05 | 核心痛点 | 用户任务、阻碍与现有办法不足 | 决定优先解决什么 |
| D06 | 核心资源 | 已有产品、研发、供应与渠道能力 | 决定能够承诺什么 |
| D07 | 品类选择 | 机会、用户认知与企业匹配 | 决定以何身份参与竞争 |
| D08 | 品牌定位 | 人群、品类、价值与兑现能力 | 决定品牌角色 |
| D09 | 主导价值 | 用户重要性、产品事实与竞争差异 | 决定优先记住什么 |
| D10 | 支持利益 | 证明价值与消除购买障碍的信息 | 组织次级卖点 |
| D11 | 战略大单品 | 需求、资源、价格供应与渠道比较 | 决定用哪个产品承接 |
| D12 | 产品名称 | 已知品类、利益、形态与认知线索 | 降低理解成本 |
| D13 | 主传播语言 | 主导价值、场景与用户语言 | 建立复述与传播 |
| D14 | 信任体系 | 每项承诺对应的证据与状态 | 支撑可信判断 |
| D15 | 视觉资产 | 价值、感受与产品可识别特征 | 形成长期识别 |
| D16 | 沟通矩阵 | 人群、阶段、触点和购买任务 | 指导信息分工 |
| D17 | 落地计划 | 资源、负责人、时间与优先级 | 转成执行行动 |
| D18 | 验证指标 | 原始目标、基线、口径与数据条件 | 判断是否成立 |

一旦D09主导价值变化，应重新检查D11—D16；不能只替换口号，保留相互矛盾的产品、证据与画面。

## 4. 判断规则：出现不同情况时如何套用

| 实际情况 | 使用规则 | 不应直接写出的结论 |
| --- | --- | --- |
| 用户主要不认识产品品类 | 先用已知母品类解释，再加入利益描述 | 起了新名字就建立了新品类 |
| 竞品也强调同一价值 | 比较具体对象、条件、产品、证据和体验差别 | 竞品没有占据这个价值 |
| 只有技术名，没有用户利益 | 写清技术如何帮助用户完成任务 | 技术越复杂，用户越愿意买 |
| 功效尚无足够证据 | 写“拟验证主张”，先设计证据任务 | 用效果图当作功效证明 |
| 价格和供应资料不足 | 将大单品标成候选，列经营假设 | 已具备规模化盈利条件 |
| 品牌已有可识别资产 | 判断保留、强化或调整的具体理由 | 为了升级而整体推翻 |
| 没有角色叙事需求 | 优先使用产品、字形、图形或摄影 | 每个品牌都必须有IP |
| 项目只涉及某个单品 | 区分品牌定位与产品利益，不改写无关母品牌策略 | 产品名等于整个品牌定位 |
| 缺少趋势、竞品或用户材料 | 保留假设，提出验证问题 | 为章节完整编造趋势和调研 |
